================================================================================
SALESFORCE AI CHATBOT — COMPLETE IMPLEMENTATION PROMPT
================================================================================

Build a production-ready AI-powered chatbot for Salesforce. The chatbot lives
in a floating drawer panel on any Lightning page (FAB that slides open a full-
height drawer). When a user navigates to a record page, the chatbot automatically
detects the record context, queries Salesforce data + external systems (ERP, BI),
and sends everything to OpenAI GPT-4o. The LLM returns typed structured JSON
that the LWC renders as rich visual components: KPI cards, charts, comparison
tables, timelines, alerts, rich record summaries, and create/update confirmation
cards.

================================================================================
CRITICAL IMPLEMENTATION RULES (learned from production deployment)
================================================================================

1. CALLOUT-BEFORE-DML ORDER (CRITICAL):
   Salesforce forbids HTTP callouts after any DML in the same transaction.
   In LNChatController.sendMessage(), ALL callouts (context build, ERP, BI,
   OpenAI) MUST happen BEFORE any DML (session create/update, message save).
   Wrong order causes: "You have uncommitted work pending. Please commit or
   rollback before calling out."

2. LWC @api RESERVED NAMES:
   Properties whose names start with "data" are RESERVED in LWC and cannot be
   used as @api properties. Use chartSeries instead of datasets.
   HTML attribute binding uses kebab-case: chart-series={chartDatasets}.
   Other banned @api names: data, slot, key, ref, is.

3. NAMED CREDENTIAL XML:
   Use <endpoint> not <url> in namedCredential-meta.xml.
   Use protocol=NoAuthentication + principalType=Anonymous for all named
   credentials (OpenAI, ERP, BI, Anthropic). Users configure real auth in
   Setup UI.

4. UTILITY BAR LWC COMPONENT:
   Component MUST have @api label = 'AI Assistant' in JS.
   The js-meta.xml MUST list lightning__UtilityBar as a target and declare the
   label property in a targetConfig for lightning__UtilityBar.
   IMPORTANT: panelWidth and panelHeight are NOT @api properties — they are
   configured in App Manager UI only.

5. UTILITY BAR — PREFERRED DEPLOYMENT: Use lnchatDrawer.
   lnchatDrawer is a standalone LWC (FAB + sliding drawer) that can be placed
   on any Lightning page via App Builder. It hosts c-lnchat-shell with
   display-mode="drawer". This avoids the FlexiPage validation error.
   Add via: App Builder → drag lnchatDrawer to any page section.

6. FLEXIPAGE UTILITY BAR — CANNOT DEPLOY VIA METADATA:
   Salesforce platform validation ALWAYS rejects custom LWC components in
   utility bar FlexiPages deployed via sf CLI / Metadata API with error:
   "Invalid component [c:lnchatShell]: missing required decorator property [label]"
   This is a known Salesforce platform limitation. Deploy everything else, then
   configure the Utility Bar item via Setup → App Manager UI if needed. See
   POST-DEPLOYMENT SETUP section below.

7. CUSTOMAPPLICATION utilityBar FIELD:
   The <utilityBar> element in a CustomApplication is a SIMPLE STRING (the name
   of a FlexiPage), not an inline block. Structure:
   <utilityBar>AI_Assistant_UtilityBar</utilityBar>

8. CHATBOT HISTORY FLEX LAYOUT:
   The lnchatHistory host element needs :host { flex:1; min-height:0;
   display:flex; flex-direction:column; } in its CSS so the history scrolls
   internally and the input stays anchored at the bottom of the panel.
   Without this, long responses push the input off-screen (clipped by
   overflow:hidden on the panel).

9. CHATTER TAB:
   Do NOT include standard-Chatter in CustomApplication tabs — it's unsupported
   in Lightning apps and causes deploy failure.

10. STATIC RESOURCE (Chart.js):
    Download Chart.js v4.4.0 UMD bundle before deploying:
    curl -L "https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js" \
      -o force-app/main/default/staticresources/chartjs.js

11. OPENAI API KEY:
    The customMetadata file ships with placeholder "YOUR_OPENAI_API_KEY_HERE".
    After deployment, set real key via:
    Setup → Custom Metadata Types → AI Config → Manage Records → Default → Edit

12. RECORD ACTION WRITE FLOW — CALLOUT RESTRICTION:
    executeRecordAction() performs DML only (no callouts). It is a separate
    @AuraEnabled method from sendMessage(). Never combine callouts + DML in
    the same transaction when they are avoidable.

13. RECORD ACTION DUPLICATE BYPASS:
    LNChatRecordActionService.executeAction() accepts a bypassDuplicate Boolean.
    When the user confirms past a duplicate warning, lnchatShell stores the
    pending action in _pendingBypassAction and re-calls handleRecordActionConfirm
    with bypassDuplicate=true. The lnchatAlertBanner fires 'alertproceed' /
    'alertcancel' events (bubbling, composed) which lnchatShell listens for via
    onalertproceed / onalertcancel on the c-lnchat-history element.

14. NAVIGATIONMIXIN IN LNCHATSHELL:
    lnchatShell must extend NavigationMixin(LightningElement) (not just
    LightningElement) to support handleRecordNavigate() for navigating to
    records from c-lnchat-record-summary clickable links. lnchatRecordSummary
    fires a 'recordnavigate' event; lnchatShell listens on c-lnchat-history via
    onrecordnavigate.

15. RECORD SUMMARY RECORD ID ENRICHMENT:
    The LLM may not reliably include Salesforce record IDs in record_summary
    section items. LNChatController.enrichSummaryRecordIds() post-processes
    the LLM JSON after the callout but before DML — it builds a name→Id lookup
    from contextData.relatedRecords and injects missing recordIds. This runs
    after the LLM call and before the DTO parse.

16. QUERYSELECTOR TAG NAMES MUST MATCH COMPONENT FOLDER NAMES (CRITICAL):
    LWC folder name determines the kebab-case HTML tag used in querySelector.
    When components are renamed, ALL querySelector string literals in JS files
    must be updated manually — sed on .html files alone is NOT sufficient.
    Example: folder "lnchatHistory" → tag "c-lnchat-history"
    lnchatShell.js uses: this.template.querySelector('c-lnchat-history')
    If you use 'c-chatbot-history' after rename, querySelector returns null
    and the chat panel will appear blank (all addMessage calls silently no-op).

17. DISPLAYMODE PROPERTY:
    lnchatShell accepts @api displayMode = 'utility' | 'sidebar' | 'drawer'.
    The minimize button is hidden when displayMode is 'sidebar' or 'drawer'.
    lnchatDrawer passes display-mode="drawer" to c-lnchat-shell.

18. FILE ATTACHMENTS:
    lnchatInput supports file attachments via browser FileReader API.
    Dispatches messagesend with detail: { message, attachment }.
    lnchatShell passes attachmentJson to LNChatController.sendMessage().
    Images/PDFs: readAsDataURL → base64 data URL (max 3 MB).
    CSV/TXT/JSON: readAsText → plain string (max 500 KB).
    DOCX/DOC: rejected client-side with attacherror event.

public with sharing class LNChatController {

    @AuraEnabled
    public static Map<String, Object> sendMessage(
        String userMessage,
        String recordId,
        String objectApiName,
        String conversationHistoryJson,
        String attachmentJson
    ) {
        try {
            if (String.isBlank(userMessage)) {
                throw new AuraHandledException('User message cannot be empty');
            }

            // All callouts must happen before any DML
            LNChatContextBuilderService contextBuilder = new LNChatContextBuilderService();
            Map<String, Object> contextData = contextBuilder.buildContext(recordId, objectApiName);

            List<Map<String, String>> conversationHistory = parseConversationHistory(conversationHistoryJson);

            LNChatLLMService llmService = new LNChatLLMService();
            String llmResponseJson = llmService.chat(conversationHistory, userMessage, contextData, attachmentJson);

            // Inject record IDs into record_summary items using context data (more reliable than LLM)
            llmResponseJson = enrichSummaryRecordIds(llmResponseJson, contextData);

            LNChatResponseDTO responseDTO = LNChatResponseDTO.fromJson(llmResponseJson);

            // DML after all callouts are complete
            String sessionId = getOrCreateSession(recordId, objectApiName);
            saveChatMessage(sessionId, 'user', userMessage, null);
            saveChatMessage(sessionId, 'assistant', llmResponseJson, responseDTO.responseType);

            Map<String, Object> result = new Map<String, Object>{
                'responseType' => responseDTO.responseType,
                'title' => responseDTO.title,
                'summary' => responseDTO.summary,
                'data' => responseDTO.data,
                'actions' => serializeActions(responseDTO.actions),
                'rawJson' => responseDTO.rawJson,
                'sessionId' => sessionId
            };

            return result;

        } catch (AuraHandledException ahe) {
            throw ahe;
        } catch (Exception e) {
            System.debug(LoggingLevel.ERROR, 'LNChatController.sendMessage error: ' + e.getMessage() + ' | ' + e.getStackTraceString());
            throw new AuraHandledException('An unexpected error occurred: ' + e.getMessage());
        }
    }

    @AuraEnabled(cacheable=true)
    public static List<Map<String, Object>> getConversationHistory(String recordId) {
        List<Map<String, Object>> messages = new List<Map<String, Object>>();

        if (String.isBlank(recordId)) {
            return messages;
        }

        try {
            List<LNChatSession__c> sessions = [
                SELECT Id
                FROM LNChatSession__c
                WHERE RecordId__c = :recordId
                ORDER BY LastActivityDate__c DESC
                LIMIT 1
            ];

            if (sessions.isEmpty()) {
                return messages;
            }

            String sessionId = sessions[0].Id;

            List<LNChatMessage__c> chatMessages = [
                SELECT Role__c, Content__c, ResponseType__c, CreatedDate
                FROM LNChatMessage__c
                WHERE Session__c = :sessionId
                ORDER BY CreatedDate ASC
                LIMIT 50
            ];

            for (LNChatMessage__c msg : chatMessages) {
                messages.add(new Map<String, Object>{
                    'role' => msg.Role__c,
                    'content' => msg.Content__c,
                    'responseType' => msg.ResponseType__c,
                    'timestamp' => String.valueOf(msg.CreatedDate)
                });
            }

        } catch (Exception e) {
            System.debug(LoggingLevel.WARN, 'getConversationHistory failed: ' + e.getMessage());
        }

        return messages;
    }

    @AuraEnabled
    public static Map<String, Object> executeRecordAction(
        String objectApiName,
        String operation,
        String recordId,
        String fieldsJson,
        String currentPageRecordId,
        Boolean bypassDuplicate
    ) {
        try {
            Map<String, Object> fields = new Map<String, Object>();
            if (String.isNotBlank(fieldsJson)) {
                fields = (Map<String, Object>) JSON.deserializeUntyped(fieldsJson);
            }
            return LNChatRecordActionService.executeAction(objectApiName, operation, recordId, fields, currentPageRecordId, bypassDuplicate == true);
        } catch (AuraHandledException ahe) {
            throw ahe;
        } catch (Exception e) {
            System.debug(LoggingLevel.ERROR, 'executeRecordAction error: ' + e.getMessage());
            throw new AuraHandledException('Record action failed: ' + e.getMessage());
        }
    }

    @AuraEnabled
    public static void clearConversationHistory(String recordId) {
        if (String.isBlank(recordId)) {
            return;
        }

        try {
            List<LNChatSession__c> sessions = [
                SELECT Id
                FROM LNChatSession__c
                WHERE RecordId__c = :recordId
                LIMIT 1
            ];

            if (!sessions.isEmpty()) {
                List<LNChatMessage__c> messagesToDelete = [
                    SELECT Id
                    FROM LNChatMessage__c
                    WHERE Session__c = :sessions[0].Id
                ];
                if (!messagesToDelete.isEmpty()) {
                    delete messagesToDelete;
                }
                delete sessions[0];
            }
        } catch (Exception e) {
            throw new AuraHandledException('Failed to clear history: ' + e.getMessage());
        }
    }

    private static String getOrCreateSession(String recordId, String objectApiName) {
        if (String.isBlank(recordId)) {
            return null;
        }

        List<LNChatSession__c> existingSessions = [
            SELECT Id
            FROM LNChatSession__c
            WHERE RecordId__c = :recordId
            LIMIT 1
        ];

        if (!existingSessions.isEmpty()) {
            LNChatSession__c session = existingSessions[0];
            session.LastActivityDate__c = System.now();
            update session;
            return session.Id;
        }

        LNChatSession__c newSession = new LNChatSession__c(
            RecordId__c = recordId,
            ObjectApiName__c = objectApiName,
            LastActivityDate__c = System.now()
        );
        insert newSession;
        return newSession.Id;
    }

    private static void saveChatMessage(String sessionId, String role, String content, String responseType) {
        if (String.isBlank(sessionId)) {
            return;
        }

        try {
            LNChatMessage__c message = new LNChatMessage__c(
                Session__c = sessionId,
                Role__c = role,
                Content__c = content != null && content.length() > 131072 ? content.substring(0, 131072) : content,
                ResponseType__c = responseType
            );
            insert message;
        } catch (Exception e) {
            System.debug(LoggingLevel.WARN, 'saveChatMessage failed: ' + e.getMessage());
        }
    }

    private static List<Map<String, String>> parseConversationHistory(String historyJson) {
        List<Map<String, String>> history = new List<Map<String, String>>();

        if (String.isBlank(historyJson)) {
            return history;
        }

        try {
            List<Object> parsed = (List<Object>) JSON.deserializeUntyped(historyJson);
            for (Object item : parsed) {
                if (item instanceof Map<String, Object>) {
                    Map<String, Object> itemMap = (Map<String, Object>) item;
                    String role = (String) itemMap.get('role');
                    String content = (String) itemMap.get('content');
                    if (String.isNotBlank(role) && String.isNotBlank(content)) {
                        history.add(new Map<String, String>{
                            'role' => role,
                            'content' => content
                        });
                    }
                }
            }
        } catch (Exception e) {
            System.debug(LoggingLevel.WARN, 'parseConversationHistory failed: ' + e.getMessage());
        }

        return history;
    }

    private static List<Map<String, Object>> serializeActions(List<LNChatResponseDTO.ActionDTO> actions) {
        List<Map<String, Object>> result = new List<Map<String, Object>>();
        if (actions == null) {
            return result;
        }
        for (LNChatResponseDTO.ActionDTO action : actions) {
            result.add(new Map<String, Object>{
                'label' => action.label,
                'flowApiName' => action.flowApiName,
                'inputVariables' => action.inputVariables
            });
        }
        return result;
    }

    // Post-process record_summary responses to inject Salesforce record IDs into section items.
    // The LLM has the IDs in context but may not reliably include them — we look them up here instead.
    private static String enrichSummaryRecordIds(String responseJson, Map<String, Object> contextData) {
        if (String.isBlank(responseJson) || contextData == null) return responseJson;
        try {
            Map<String, Object> response = (Map<String, Object>) JSON.deserializeUntyped(responseJson);
            if ((String) response.get('responseType') != 'record_summary') return responseJson;

            // Build name/subject → Id lookup across all related record lists
            Map<String, String> nameToId = new Map<String, String>();

            Map<String, Object> related = (Map<String, Object>) contextData.get('relatedRecords');
            if (related != null) {
                for (String key : related.keySet()) {
                    Object val = related.get(key);
                    if (!(val instanceof List<Object>)) continue;
                    for (Object obj : (List<Object>) val) {
                        if (!(obj instanceof Map<String, Object>)) continue;
                        Map<String, Object> rec = (Map<String, Object>) obj;
                        String recId = (String) rec.get('Id');
                        if (String.isBlank(recId)) continue;
                        // Name field (Account, Opportunity, Case, Order, Contract, Quote)
                        String recName = (String) rec.get('Name');
                        if (String.isNotBlank(recName)) nameToId.put(recName.toLowerCase(), recId);
                        // Subject (Task)
                        String subject = (String) rec.get('Subject');
                        if (String.isNotBlank(subject)) nameToId.put(subject.toLowerCase(), recId);
                        // Contact: FirstName + LastName
                        String lastName = (String) rec.get('LastName');
                        if (String.isNotBlank(lastName)) {
                            String firstName = (String) rec.get('FirstName');
                            String full = (String.isNotBlank(firstName) ? firstName + ' ' : '') + lastName;
                            nameToId.put(full.toLowerCase(), recId);
                        }
                    }
                }
            }

            // Also include the main record itself
            Map<String, Object> sfRecord = (Map<String, Object>) contextData.get('salesforceRecord');
            if (sfRecord != null) {
                String recId = (String) sfRecord.get('Id');
                String recName = (String) sfRecord.get('Name');
                if (String.isNotBlank(recId) && String.isNotBlank(recName)) {
                    nameToId.put(recName.toLowerCase(), recId);
                }
            }

            if (nameToId.isEmpty()) return responseJson;

            // Walk sections → items and inject missing recordIds
            Map<String, Object> data = (Map<String, Object>) response.get('data');
            if (data == null) return responseJson;
            List<Object> sections = (List<Object>) data.get('sections');
            if (sections == null) return responseJson;

            Boolean modified = false;
            for (Object secObj : sections) {
                if (!(secObj instanceof Map<String, Object>)) continue;
                List<Object> items = (List<Object>) ((Map<String, Object>) secObj).get('items');
                if (items == null) continue;
                for (Object itmObj : items) {
                    if (!(itmObj instanceof Map<String, Object>)) continue;
                    Map<String, Object> item = (Map<String, Object>) itmObj;
                    if (String.isNotBlank((String) item.get('recordId'))) continue;
                    String itemName = (String) item.get('name');
                    if (String.isBlank(itemName)) continue;
                    String foundId = nameToId.get(itemName.toLowerCase());
                    if (String.isNotBlank(foundId)) {
                        item.put('recordId', foundId);
                        modified = true;
                    }
                }
            }

            return modified ? JSON.serialize(response) : responseJson;

        } catch (Exception e) {
            System.debug(LoggingLevel.WARN, 'enrichSummaryRecordIds failed: ' + e.getMessage());
            return responseJson;
        }
    }
}

    public String chat(List<Map<String, String>> conversationHistory, String userMessage, Map<String, Object> contextData, String attachmentJson) {
        String apiKey = getApiKey();
        String modelName = getModelName();
        Integer maxTokens = getMaxTokens();

        String contextJson = JSON.serialize(contextData);
        String systemPromptWithContext = SYSTEM_PROMPT
            + '\n\nTODAY\'S DATE: ' + String.valueOf(System.today()) + ' (use this to compute relative dates like "today + 30 days")'
            + '\n\nCURRENT RECORD CONTEXT (use this data to answer):\n'
            + contextJson;

        // Use Map<String, Object> for content so we can support multimodal (image/file) payloads
        List<Map<String, Object>> messages = new List<Map<String, Object>>();
        messages.add(new Map<String, Object>{ 'role' => 'system', 'content' => systemPromptWithContext });

        if (conversationHistory != null) {
            for (Map<String, String> histMsg : conversationHistory) {
                messages.add(new Map<String, Object>{
                    'role' => histMsg.get('role'),
                    'content' => histMsg.get('content')
                });
            }
        }

        // Build the user turn — plain text or multimodal depending on attachment
        if (String.isNotBlank(attachmentJson)) {
            try {
                Map<String, Object> att = (Map<String, Object>) JSON.deserializeUntyped(attachmentJson);
                String attType = (String) att.get('type');
                String attName = (String) att.get('name');
                String prompt = String.isNotBlank(userMessage) ? userMessage : 'Please analyze this file and respond in the required JSON format.';

                if (attType == 'image') {
                    String dataUrl = (String) att.get('base64Data');
                    List<Object> parts = new List<Object>{
                        new Map<String, String>{ 'type' => 'text', 'text' => prompt },
                        new Map<String, Object>{
                            'type' => 'image_url',
                            'image_url' => new Map<String, String>{ 'url' => dataUrl }
                        }
                    };
                    messages.add(new Map<String, Object>{ 'role' => 'user', 'content' => parts });

                } else if (attType == 'text') {
                    String fileContent = (String) att.get('content');
                    String enriched = prompt + '\n\n[Attached file: ' + attName + ']\n' + fileContent;
                    messages.add(new Map<String, Object>{ 'role' => 'user', 'content' => enriched });

                } else if (attType == 'pdf') {
                    String dataUrl = (String) att.get('base64Data');
                    List<Object> parts = new List<Object>{
                        new Map<String, String>{ 'type' => 'text', 'text' => prompt },
                        new Map<String, Object>{
                            'type' => 'file',
                            'file' => new Map<String, String>{
                                'filename' => attName,
                                'file_data' => dataUrl
                            }
                        }
                    };
                    messages.add(new Map<String, Object>{ 'role' => 'user', 'content' => parts });

                } else {
                    messages.add(new Map<String, Object>{ 'role' => 'user', 'content' => prompt });
                }
            } catch (Exception e) {
                System.debug(LoggingLevel.WARN, 'LNChatLLMService: failed to build attachment content — ' + e.getMessage());
                messages.add(new Map<String, Object>{ 'role' => 'user', 'content' => userMessage });
            }
        } else {
            messages.add(new Map<String, Object>{ 'role' => 'user', 'content' => userMessage });
        }

        Map<String, Object> requestBody = new Map<String, Object>{
            'model' => modelName,
            'max_completion_tokens' => maxTokens,
            'messages' => messages,
            'response_format' => new Map<String, String>{ 'type' => 'json_object' }
        };

        return executeRequest(requestBody, apiKey, false);
    }

    private String executeRequest(Map<String, Object> requestBody, String apiKey, Boolean isRetry) {
        try {
            HttpRequest req = new HttpRequest();
            req.setEndpoint(NAMED_CREDENTIAL + API_PATH);
            req.setMethod('POST');
            req.setHeader('Content-Type', 'application/json');
            req.setHeader('Authorization', 'Bearer ' + apiKey);
            req.setBody(JSON.serialize(requestBody));
            req.setTimeout(60000);

            Http http = new Http();
            HttpResponse res = http.send(req);

            Integer statusCode = res.getStatusCode();

            if (statusCode == 200) {
                return parseSuccessResponse(res.getBody());
            }

            if (statusCode == 429 && !isRetry) {
                Long startWait = System.currentTimeMillis();
                while (System.currentTimeMillis() - startWait < RETRY_WAIT_MS) {
                    // busy wait — Apex has no Thread.sleep
                }
                return executeRequest(requestBody, apiKey, true);
            }

            throw new CalloutException('OpenAI API error ' + statusCode + ': ' + res.getBody());

        } catch (CalloutException ce) {
            throw ce;
        } catch (Exception e) {
            throw new AuraHandledException('LLM request failed: ' + e.getMessage());
        }
    }

    private String parseSuccessResponse(String responseBody) {
        try {
            Map<String, Object> parsed = (Map<String, Object>) JSON.deserializeUntyped(responseBody);
            List<Object> choices = (List<Object>) parsed.get('choices');
            if (choices != null && !choices.isEmpty()) {
                Map<String, Object> firstChoice = (Map<String, Object>) choices[0];
                String finishReason = (String) firstChoice.get('finish_reason');
                Map<String, Object> message = (Map<String, Object>) firstChoice.get('message');
                if (message != null) {
                    String content = (String) message.get('content');
                    if (String.isNotBlank(content)) {
                        return content.trim();
                    }
                }
                if ('length'.equals(finishReason)) {
                    throw new AuraHandledException('Response was cut off — the request is too long for the current token limit. Increase MaxTokens in AI Config custom metadata (currently ' + DEFAULT_MAX_TOKENS + ').');
                }
            }
            throw new AuraHandledException('No content in OpenAI response');
        } catch (Exception e) {
            throw new AuraHandledException('Failed to parse OpenAI response: ' + e.getMessage());
        }
    }

    private String getApiKey() {
        List<AI_Config__mdt> configs = [
            SELECT ApiKey__c
            FROM AI_Config__mdt
            WHERE DeveloperName = 'Default'
            LIMIT 1
        ];
        if (!configs.isEmpty() && String.isNotBlank(configs[0].ApiKey__c)) {
            return configs[0].ApiKey__c;
        }
        throw new AuraHandledException('OpenAI API key not configured in AI_Config__mdt');
    }

    private String getModelName() {
        List<AI_Config__mdt> configs = [
            SELECT ModelName__c
            FROM AI_Config__mdt
            WHERE DeveloperName = 'Default'
            LIMIT 1
        ];
        if (!configs.isEmpty() && String.isNotBlank(configs[0].ModelName__c)) {
            return configs[0].ModelName__c;
        }
        return DEFAULT_MODEL;
    }

    private Integer getMaxTokens() {
        List<AI_Config__mdt> configs = [
            SELECT MaxTokens__c
            FROM AI_Config__mdt
            WHERE DeveloperName = 'Default'
            LIMIT 1
        ];
        if (!configs.isEmpty() && configs[0].MaxTokens__c != null) {
            return Integer.valueOf(configs[0].MaxTokens__c);
        }
        return DEFAULT_MAX_TOKENS;
    }
}

public with sharing class LNChatResponseDTO {
    public String responseType { get; set; }
    public String title { get; set; }
    public String summary { get; set; }
    public Map<String, Object> data { get; set; }
    public List<ActionDTO> actions { get; set; }
    public String rawJson { get; set; }

    public class ActionDTO {
        public String label { get; set; }
        public String flowApiName { get; set; }
        public Map<String, Object> inputVariables { get; set; }

        public ActionDTO() {
            this.inputVariables = new Map<String, Object>();
        }
    }

    public LNChatResponseDTO() {
        this.actions = new List<ActionDTO>();
        this.data = new Map<String, Object>();
    }

    public static LNChatResponseDTO fromJson(String jsonString) {
        if (String.isBlank(jsonString)) {
            return buildErrorDTO('Empty response from AI service');
        }

        LNChatResponseDTO dto = new LNChatResponseDTO();
        dto.rawJson = jsonString;

        try {
            Map<String, Object> parsed = (Map<String, Object>) JSON.deserializeUntyped(jsonString);

            dto.responseType = (String) parsed.get('responseType');
            dto.title = (String) parsed.get('title');
            dto.summary = (String) parsed.get('summary');

            Object dataObj = parsed.get('data');
            if (dataObj instanceof Map<String, Object>) {
                dto.data = (Map<String, Object>) dataObj;
            } else {
                dto.data = new Map<String, Object>();
            }

            Object actionsObj = parsed.get('actions');
            dto.actions = new List<ActionDTO>();
            if (actionsObj instanceof List<Object>) {
                for (Object actionItem : (List<Object>) actionsObj) {
                    if (actionItem instanceof Map<String, Object>) {
                        Map<String, Object> actionMap = (Map<String, Object>) actionItem;
                        ActionDTO action = new ActionDTO();
                        action.label = (String) actionMap.get('label');
                        action.flowApiName = (String) actionMap.get('flowApiName');
                        Object inputVarsObj = actionMap.get('inputVariables');
                        if (inputVarsObj instanceof Map<String, Object>) {
                            action.inputVariables = (Map<String, Object>) inputVarsObj;
                        }
                        dto.actions.add(action);
                    }
                }
            }

            if (String.isBlank(dto.responseType)) {
                dto.responseType = 'summary';
            }

        } catch (Exception e) {
            return buildErrorDTO('Failed to parse AI response: ' + e.getMessage());
        }

        return dto;
    }

    private static LNChatResponseDTO buildErrorDTO(String errorMessage) {
        LNChatResponseDTO dto = new LNChatResponseDTO();
        dto.responseType = 'alert';
        dto.title = 'Error';
        dto.summary = errorMessage;
        dto.data = new Map<String, Object>{
            'severity' => 'critical',
            'alertTitle' => 'AI Response Error',
            'message' => errorMessage,
            'details' => new List<String>{ errorMessage }
        };
        dto.actions = new List<ActionDTO>();
        dto.rawJson = '{}';
        return dto;
    }
}

public with sharing class LNChatContextBuilderService {

    public Map<String, Object> buildContext(String recordId, String objectApiName) {
        Map<String, Object> context = new Map<String, Object>();

        if (String.isBlank(recordId) || String.isBlank(objectApiName)) {
            context.put('error', 'Missing recordId or objectApiName');
            return context;
        }

        context.put('objectApiName', objectApiName);
        context.put('recordId', recordId);

        Map<String, Object> sfRecord = querySalesforceRecord(recordId, objectApiName);
        context.put('salesforceRecord', sfRecord);

        Map<String, Object> relatedRecords = queryRelatedRecords(recordId, objectApiName, sfRecord);
        context.put('relatedRecords', relatedRecords);

        String externalId = extractExternalId(sfRecord, objectApiName);

        LNChatERPService erpService = new LNChatERPService();
        Map<String, Object> erpData;
        try {
            erpData = erpService.getRecordData(externalId);
        } catch (Exception e) {
            System.debug(LoggingLevel.WARN, 'ERP data fetch failed: ' + e.getMessage());
            erpData = new Map<String, Object>{ 'available' => false, 'reason' => e.getMessage() };
        }
        context.put('erpData', erpData);

        LNChatBIService biService = new LNChatBIService();
        Map<String, Object> biData;
        try {
            biData = biService.getMetrics(externalId);
        } catch (Exception e) {
            System.debug(LoggingLevel.WARN, 'BI data fetch failed: ' + e.getMessage());
            biData = new Map<String, Object>{ 'available' => false, 'reason' => e.getMessage() };
        }
        context.put('biData', biData);

        context.put('contextBuildTimestamp', String.valueOf(System.now()));

        return context;

        Map<String, Object> result = new Map<String, Object>();

        try {
            Schema.SObjectType sObjType = Schema.getGlobalDescribe().get(objectApiName);
            if (sObjType == null) {
                result.put('error', 'Unknown object type: ' + objectApiName);
                return result;
            }

            Schema.DescribeSObjectResult describeResult = sObjType.getDescribe();
            Map<String, Schema.SObjectField> fieldMap = describeResult.fields.getMap();

            List<String> queryableFields = new List<String>();
            for (String fieldName : fieldMap.keySet()) {
                Schema.DescribeFieldResult fieldDescribe = fieldMap.get(fieldName).getDescribe();
                if (fieldDescribe.isAccessible() && !fieldDescribe.isCalculated()) {
                    queryableFields.add(fieldName);
                }
            }

            if (queryableFields.isEmpty()) {
                queryableFields.add('Id');
            }

            String soql = 'SELECT ' + String.join(queryableFields, ', ')
                + ' FROM ' + objectApiName
                + ' WHERE Id = :recordId'
                + ' LIMIT 1';

            List<SObject> records = Database.query(soql);
            if (!records.isEmpty()) {
                Map<String, Object> populatedFields = records[0].getPopulatedFieldsAsMap();
                for (String key : populatedFields.keySet()) {
                    result.put(key, populatedFields.get(key));
                }
            }

        } catch (Exception e) {
            System.debug(LoggingLevel.ERROR, 'querySalesforceRecord failed: ' + e.getMessage());
            result.put('error', e.getMessage());
        }

        return result;
    }

    private List<Map<String, Object>> convertOCRToMapList(List<OpportunityContactRole> roles) {
        List<Map<String, Object>> result = new List<Map<String, Object>>();
        for (OpportunityContactRole ocr : roles) {
            Map<String, Object> row = new Map<String, Object>{
                'contactId' => ocr.ContactId,
                'role'      => ocr.Role,
                'isPrimary' => ocr.IsPrimary
            };
            if (ocr.Contact != null) {
                row.put('name',  ocr.Contact.Name);
                row.put('title', ocr.Contact.Title);
                row.put('email', ocr.Contact.Email);
                row.put('phone', ocr.Contact.Phone);
            }
            result.add(row);
        }
        return result;
    }

    private String extractExternalId(Map<String, Object> sfRecord, String objectApiName) {
        Object sourceId = sfRecord.get('SourceSystemIdentifier__c');
        if (sourceId != null && String.isNotBlank(String.valueOf(sourceId))) {
            return String.valueOf(sourceId);
        }

        Object extId = sfRecord.get('External_Id__c');
        if (extId != null && String.isNotBlank(String.valueOf(extId))) {
            return String.valueOf(extId);
        }

        Object recordId = sfRecord.get('Id');
        return recordId != null ? String.valueOf(recordId) : '';
    }

                    'isDuplicate' => true,
                    'isAmbiguous' => false,
                    'duplicates'  => duplicates
                };
            }
        }

            return doCreate(objectApiName, fields);

    private static Map<String, Object> doCreate(String objectApiName, Map<String, Object> fields) {
        SObject record = Schema.getGlobalDescribe().get(objectApiName).newSObject();
        applyFields(record, objectApiName, fields);
        insert record;
        return new Map<String, Object>{ 'recordId' => record.Id, 'success' => true };
    }

    private static Map<String, Object> doUpdate(String objectApiName, String recordId, Map<String, Object> fields) {
        SObject record = Schema.getGlobalDescribe().get(objectApiName).newSObject(recordId);
        applyFields(record, objectApiName, fields);
        update record;
        return new Map<String, Object>{ 'recordId' => recordId, 'success' => true };
    }

    private static void applyFields(SObject record, String objectApiName, Map<String, Object> fields) {
        Map<String, Schema.SObjectField> fieldMap =
            Schema.getGlobalDescribe().get(objectApiName).getDescribe().fields.getMap();

        for (String fieldName : fields.keySet()) {
            Schema.SObjectField fieldToken = fieldMap.get(fieldName.toLowerCase());
            if (fieldToken == null) continue;
            Schema.DescribeFieldResult fd = fieldToken.getDescribe();
            if (!fd.isCreateable()) continue;
            Object rawValue = fields.get(fieldName);
            if (rawValue == null) continue;
            String strValue = String.valueOf(rawValue);
            if (String.isBlank(strValue)) continue;
            try {
                Schema.DisplayType ft = fd.getType();
                if (ft == Schema.DisplayType.DATE) {
                    record.put(fieldName, Date.valueOf(strValue));
                } else if (ft == Schema.DisplayType.DATETIME) {
                    record.put(fieldName, DateTime.valueOf(strValue));
                } else if (ft == Schema.DisplayType.DOUBLE
                        || ft == Schema.DisplayType.CURRENCY
                        || ft == Schema.DisplayType.PERCENT) {
                    record.put(fieldName, Double.valueOf(strValue));
                } else if (ft == Schema.DisplayType.INTEGER) {
                    record.put(fieldName, Integer.valueOf(strValue));
                } else if (ft == Schema.DisplayType.BOOLEAN) {
                    record.put(fieldName, Boolean.valueOf(strValue));
                } else {
                    record.put(fieldName, strValue);
                }
            } catch (Exception e) {
                System.debug(LoggingLevel.WARN, 'LNChatRecordActionService: skipping field ' + fieldName + ': ' + e.getMessage());
            }
        }
    }

    // ─── Utility ──────────────────────────────────────────────────────────────

    private static String strVal(Map<String, Object> fields, String key) {
        Object val = fields.get(key);
        return val != null ? String.valueOf(val).trim() : '';
    }
}

import { LightningElement, api, wire, track } from 'lwc';
import { CurrentPageReference, NavigationMixin } from 'lightning/navigation';
import sendMessage from '@salesforce/apex/LNChatController.sendMessage';
import getConversationHistory from '@salesforce/apex/LNChatController.getConversationHistory';
import clearConversationHistory from '@salesforce/apex/LNChatController.clearConversationHistory';
import executeRecordAction from '@salesforce/apex/LNChatController.executeRecordAction';
import { ShowToastEvent } from 'lightning/platformShowToastEvent';

const OBJECT_LABELS = {
    Account: 'Account',
    Opportunity: 'Opportunity',
    Case: 'Case',
    Lead: 'Lead',
    Contact: 'Contact'
};

export default class LnchatShell extends NavigationMixin(LightningElement) {
    @api label = 'AI Assistant';
    @api displayMode = 'utility'; // 'utility' | 'sidebar' | 'drawer'

    @track recordId = '';
    @track objectApiName = '';
    @track isLoading = false;
    @track isMinimized = false;
    @track conversationHistory = [];

    _pendingBypassAction = null;

    @wire(CurrentPageReference)
    handlePageRef(pageRef) {
        if (!pageRef) return;

        const attrs = pageRef.attributes || {};
        const newRecordId = attrs.recordId || '';
        const newObjectApiName = attrs.objectApiName || '';

        if (newRecordId !== this.recordId) {
            this.recordId = newRecordId;
            this.objectApiName = newObjectApiName;
            this.conversationHistory = [];

            if (this.recordId) {
                this.loadHistory();
            } else {
                const history = this.template.querySelector('c-lnchat-history');
                if (history) history.clearMessages();
            }
        }
    }

    get hasRecord() {
        return !!this.recordId;
    }

    get contextLabel() {
        const label = OBJECT_LABELS[this.objectApiName] || this.objectApiName;
        return label ? label + ' record' : 'Current record';
    }

    get isSidebar() {
        return this.displayMode === 'sidebar';
    }

    get isDrawer() {
        return this.displayMode === 'drawer';
    }

    get panelClass() {
        let cls = 'chatbot-panel';
        if (this.isDrawer) cls += ' panel-drawer';
        else if (this.isSidebar) cls += ' panel-sidebar';
        else if (this.isMinimized) cls += ' panel-minimized';
        return cls;
    }

    async loadHistory() {
        try {
            const history = await getConversationHistory({ recordId: this.recordId });
            const historyEl = this.template.querySelector('c-lnchat-history');
            if (!historyEl) return;

            historyEl.clearMessages();
            this.conversationHistory = [];

            for (const msg of history) {
                historyEl.addMessage(msg.role, msg.content, msg.responseType);
                this.conversationHistory.push({ role: msg.role, content: msg.content });
            }
        } catch (e) {
            // Silently fail on history load — non-critical
        }
    }

    async handleMessageSend(event) {
        const { message: userMessage, attachment } = event.detail;
        if ((!userMessage && !attachment) || this.isLoading) return;

        const historyEl = this.template.querySelector('c-lnchat-history');
        if (historyEl) {
            historyEl.addMessage('user', userMessage || '', null, attachment ? attachment.name : null);
        }

        const historyContent = userMessage || (attachment ? '[File: ' + attachment.name + ']' : '');
        this.conversationHistory.push({ role: 'user', content: historyContent });
        this.isLoading = true;

        try {
            const historyJson = JSON.stringify(
                this.conversationHistory.slice(-10).map((m) => ({
                    role: m.role,
                    content: m.content
                }))
            );

            const result = await sendMessage({
                userMessage: userMessage || '',
                recordId: this.recordId || null,
                objectApiName: this.objectApiName || null,
                conversationHistoryJson: historyJson,
                attachmentJson: attachment ? JSON.stringify(attachment) : null
            });

            const assistantContent = result.rawJson || JSON.stringify({
                responseType: result.responseType,
                title: result.title,
                summary: result.summary,
                data: result.data,
                actions: result.actions
            });

            if (historyEl) {
                historyEl.addMessage('assistant', assistantContent, result.responseType);
            }

            this.conversationHistory.push({ role: 'assistant', content: assistantContent });

        } catch (error) {
            // Remove the user message we just added so failed attempts don't inflate history
            this.conversationHistory.pop();

            const errorMsg = error.body ? error.body.message : (error.message || 'Unknown error');
            this.dispatchEvent(new ShowToastEvent({
                title: 'AI Assistant Error',
                message: errorMsg,
                variant: 'error',
                mode: 'dismissable'
            }));

            if (historyEl) {
                const errorJson = JSON.stringify({
                    responseType: 'alert',
                    title: 'Error',
                    summary: errorMsg,
                    data: {
                        severity: 'critical',
                        alertTitle: 'Request Failed',
                        message: errorMsg,
                        details: []
                    },
                    actions: []
                });
                historyEl.addMessage('assistant', errorJson, 'alert');
            }
        } finally {
            this.isLoading = false;
        }
    }

    async handleClearHistory() {
        if (this.isLoading) return;

        if (this.recordId) {
            try {
                await clearConversationHistory({ recordId: this.recordId });
            } catch (e) {
                // Non-critical — clear UI anyway
            }
        }

        const historyEl = this.template.querySelector('c-lnchat-history');
        if (historyEl) historyEl.clearMessages();
        this.conversationHistory = [];
    }

    async handleRecordActionConfirm(event) {
        const { operation, objectApiName, recordId, fields, bypassDuplicate } = event.detail;
        const historyEl = this.template.querySelector('c-lnchat-history');
        this.isLoading = true;

        try {
            const result = await executeRecordAction({
                objectApiName,
                operation,
                recordId: recordId || null,
                fieldsJson: JSON.stringify(fields || {}),
                currentPageRecordId: this.recordId || null,
                bypassDuplicate: bypassDuplicate === true
            });

            let responseJson;

            if (result.isDuplicate) {
                const dups = result.duplicates || [];
                const details = dups.map((d) => {
                    const parts = [];
                    if (d.id)      parts.push('ID: ' + d.id);
                    if (d.name)    parts.push(d.name);
                    if (d.email)   parts.push('Email: ' + d.email);
                    if (d.phone)   parts.push('Phone: ' + d.phone);
                    if (d.account) parts.push('Account: ' + d.account);
                    if (d.company) parts.push('Company: ' + d.company);
                    if (d.stage)   parts.push('Stage: ' + d.stage);
                    if (d.status)  parts.push('Status: ' + d.status);
                    if (d.number)  parts.push('Case #: ' + d.number);
                    if (d.city)    parts.push(d.city + (d.state ? ', ' + d.state : ''));
                    return parts.join('  |  ');
                });

                if (result.isAmbiguous) {
                    responseJson = JSON.stringify({
                        responseType: 'alert',
                        title: 'Ambiguous Record — Action Blocked',
                        summary: 'Found ' + (dups.length + 1) + ' ' + objectApiName + ' records with the same name. Please tell me which one to update by specifying the Record ID.',
                        data: {
                            severity: 'warning',
                            alertTitle: 'Multiple ' + objectApiName + ' Records Found',
                            message: 'These records share the same name. Specify the Record ID of the one you want to update:',
                            details
                        },
                        actions: []
                    });
                } else {
                    // Store action details so user can proceed past the warning
                    this._pendingBypassAction = { operation, objectApiName, recordId, fields };
                    responseJson = JSON.stringify({
                        responseType: 'alert',
                        title: 'Duplicate Found — Confirm to Proceed',
                        summary: dups.length + ' existing record(s) already have similar values. Click "Proceed Anyway" to create the record regardless, or "Cancel" to abort.',
                        data: {
                            severity: 'warning',
                            alertTitle: 'Duplicate ' + objectApiName + ' Record(s) Found',
                            message: 'The following existing record(s) may conflict with your request:',
                            details,
                            allowBypass: true
                        },
                        actions: []
                    });
                }
            } else {
                const noun = operation === 'update' ? objectApiName + ' updated' : objectApiName + ' created';
                responseJson = JSON.stringify({
                    responseType: 'alert',
                    title: 'Success',
                    summary: noun + ' successfully.',
                    data: {
                        severity: 'success',
                        alertTitle: noun.charAt(0).toUpperCase() + noun.slice(1),
                        message: noun.charAt(0).toUpperCase() + noun.slice(1) + ' successfully.',
                        details: result.recordId ? ['Record ID: ' + result.recordId] : []
                    },
                    actions: []
                });
            }

            if (historyEl) historyEl.addMessage('assistant', responseJson, 'alert');
            this.conversationHistory.push({ role: 'assistant', content: responseJson });

        } catch (error) {
            const errorMsg = error.body ? error.body.message : (error.message || 'Record action failed');
            const errorJson = JSON.stringify({
                responseType: 'alert',
                title: 'Error',
                summary: errorMsg,
                data: {
                    severity: 'critical',
                    alertTitle: 'Action Failed',
                    message: errorMsg,
                    details: []
                },
                actions: []
            });
            if (historyEl) historyEl.addMessage('assistant', errorJson, 'alert');
        } finally {
            this.isLoading = false;
        }
    }

    handleAttachError(event) {
        this.dispatchEvent(new ShowToastEvent({
            title: 'File Attachment',
            message: event.detail.message,
            variant: 'error',
            mode: 'dismissable'
        }));
    }

    handleRecordActionCancel() {
        const cancelJson = JSON.stringify({
            responseType: 'summary',
            title: 'Cancelled',
            summary: 'Action cancelled.',
            data: {
                sections: [{ heading: '', body: 'No changes were made. Let me know if you\'d like to do something else.' }],
                badges: []
            },
            actions: []
        });
        const historyEl = this.template.querySelector('c-lnchat-history');
        if (historyEl) historyEl.addMessage('assistant', cancelJson, 'summary');
    }

    async handleAlertProceed() {
        if (!this._pendingBypassAction) return;
        const { operation, objectApiName, recordId, fields } = this._pendingBypassAction;
        this._pendingBypassAction = null;
        // Re-fire the confirm event with bypassDuplicate = true
        this.handleRecordActionConfirm({
            detail: { operation, objectApiName, recordId, fields, bypassDuplicate: true }
        });
    }

    handleAlertCancel() {
        this._pendingBypassAction = null;
        const cancelJson = JSON.stringify({
            responseType: 'summary',
            title: 'Cancelled',
            summary: 'Action cancelled. No record was created.',
            data: { sections: [], badges: [] },
            actions: []
        });
        const historyEl = this.template.querySelector('c-lnchat-history');
        if (historyEl) historyEl.addMessage('assistant', cancelJson, 'summary');
    }

    handleRecordNavigate(event) {
        const { recordId } = event.detail;
        if (!recordId) return;
        this[NavigationMixin.Navigate]({
            type: 'standard__recordPage',
            attributes: {
                recordId,
                actionName: 'view'
            }
        });
    }

    handleMinimize() {
        this.isMinimized = !this.isMinimized;

        this.dispatchEvent(new CustomEvent('utilitybarminimize', {
            bubbles: true,
            composed: true
        }));
    }
}

LWC: lnchatRecordActionCard
================================================================================

Renders a create/update confirmation card with a field table and Confirm/Cancel buttons.

@api properties:
  operation    = 'create' | 'update'
  objectApiName = string (e.g. 'Account')
  recordId     = string (Salesforce Id for update, empty for create)
  fieldsData   = object { FieldApiName: value }

Events dispatched (bubbling, composed):
  recordactionconfirm — detail: { operation, objectApiName, recordId, fields }
  recordactioncancel  — no detail

After confirm or cancel, buttons are hidden and a status badge (Submitted/Cancelled) appears.
isDone guards against double-clicks.

FIELD_LABELS map in lnchatRecordActionCard.js translates API names to human-readable labels
for the table display (e.g. 'BillingCity' → 'Billing City').

LWC: lnchatRecordSummary
================================================================================

Renders a rich record overview card: header (name + subtitle + status badge),
KPI bar (key counts), and collapsible sections with clickable record links.

@api summaryData = {} — the `data` object from a record_summary LLM response.

Structure of summaryData:
  header:   { name, subtitle, badge, badgeColor }
  kpis:     [ { label, value, sub } ]
  sections: [ { title, items: [ { recordId, name, subtitle, date, amount, badges[] } ] } ]

Fires 'recordnavigate' (bubbling, composed) with detail: { recordId } when a
section item link is clicked. lnchatShell handles this via onrecordnavigate
on c-lnchat-history and uses NavigationMixin to navigate to the record page.

Empty sections (zero items) are filtered out in the JS getter — never rendered.

================================================================================
LWC: lnchatAlertBanner
================================================================================

@api severity = 'critical | warning | info | success'
@api alertTitle, message, details (string[])
@api allowBypass = false — when true, shows "Proceed Anyway" / "Cancel" buttons
                           instead of the normal dismiss button.

Events:
  dismiss      — normal alert dismiss (not bubbling)
  alertproceed — user clicked "Proceed Anyway" (bubbling, composed)
  alertcancel  — user clicked "Cancel" on bypass prompt (bubbling, composed)

These bubble up through c-lnchat-history to lnchatShell which listens via
onalertproceed and onalertcancel on the c-lnchat-history element.

================================================================================
LWC: lnchatChartWidget
================================================================================

Loads Chart.js v4.4.0 via loadScript from Static Resource 'chartjs'.
@api chartSeries — array of { label, data[], color } objects.
Renders bar, line, donut charts using Salesforce brand palette:
['#0176d3','#1b96ff','#0e56c4','#032d60','#85c9f5','#9854cb','#2e844a','#fe9339']

CRITICAL: Chart.js mutates data arrays by adding a _chartjs property.
LWC reactive proxies are read-only and will throw on mutation.
Always clone with Array.from() before passing to Chart.js:
  Array.from(series[i].data)  // NOT series[i].data directly

Structure: { columns: ["Col A", "Col B"], rows: [["val1","val2"], ...] }
Uses SLDS data-table styling.

DEPLOYMENT STEPS
================================================================================

1. Create SFDX project:
   sf project generate --name ai-chatbot --template standard
   cd ai-chatbot

2. Authorize org:
   sf org login web --alias MY_ORG --instance-url https://login.salesforce.com

3. Download Chart.js:
   curl -L "https://cdn.jsdelivr.net/npm/chart.js@4.4.0/dist/chart.umd.min.js" \
     -o force-app/main/default/staticresources/chartjs.js

4. Create all files from this prompt (all Apex, LWC, metadata files above).

5. Create .forceignore entries for files excluded from deploy:
   # .forceignore
   force-app/main/default/flexipages/AI_Assistant_UtilityBar.flexipage-meta.xml
   force-app/main/default/applications/AI_Assistant.app-meta.xml
   force-app/main/default/customMetadata/AI_Config.Default.md-meta.xml

6. Deploy:
   sf project deploy start --source-dir force-app/main/default \
     --target-org MY_ORG --wait 15

7. Set OpenAI API key (see POST-DEPLOYMENT SETUP).

8. Add lnchatDrawer to a Lightning page via App Builder (recommended, see below).

POST-DEPLOYMENT SETUP
================================================================================

STEP 1 — Set OpenAI API Key:
  Setup → Custom Metadata Types → AI Config → Manage Records → Default → Edit
  Paste your OpenAI API key into Api Key field → Save
  Also set MaxTokens__c to 4096 (CRITICAL — values ≤2000 cause empty responses)

  Setup → Named Credentials → OpenAI GPT → verify endpoint is https://api.openai.com
  The chatbot passes the API key via Authorization header in Apex — no auth setup needed in the NC itself.

  d. Click "Add Utility Item" → Search "lnchatShell" → select it
  e. Configure: Label=AI Assistant, Icon=utility:einstein, Width=420, Height=580

KNOWN ISSUES AND RESOLUTION NOTES
================================================================================

Issue: "You have uncommitted work pending. Please commit or rollback before calling out"
Fix:   Move all HTTP callouts BEFORE any DML in LNChatController.sendMessage().
       (getOrCreateSession and saveChatMessage must come AFTER the LLM call)

Issue: LWC1107 — "Properties starting with 'data' are reserved attributes"
Fix:   Rename @api datasets to @api chartSeries in lnchatChartWidget.js.
       Update HTML template binding to chart-series={...}

Issue: Named credential deploy error "Element url invalid"
Fix:   Use <endpoint> not <url> in namedCredential-meta.xml XML

Issue: "Tab standard-Chatter can't be added to Lightning app"
Fix:   Remove standard-Chatter from app-meta.xml tabs list

Issue: FlexiPage "Invalid component: missing required decorator property [label]"
Fix:   This is a Salesforce platform limitation — cannot deploy custom LWC
       components in utility bar FlexiPages via metadata. Use lnchatDrawer
       on App Builder pages instead (recommended), or add via App Manager UI.

Issue: Chat input inaccessible after AI response (pushed off-screen)
Fix:   Add :host { flex:1; min-height:0; display:flex; flex-direction:column; }
       to lnchatHistory.css

Issue: Chat panel appears completely blank — no messages render, no chips
Fix:   querySelector string literals in lnchatShell.js must match the component
       folder name. After rename, JS files must be updated manually:
       this.template.querySelector('c-lnchat-history')  // CORRECT
       this.template.querySelector('c-chatbot-history') // WRONG after rename
       All 7 querySelector calls in lnchatShell.js use 'c-lnchat-history'.
       (sed on .html files does NOT fix JS string literals)

Issue: Record navigation from record_summary clickable links does not work
Fix:   lnchatShell must extend NavigationMixin(LightningElement). Import
       NavigationMixin from 'lightning/navigation'. lnchatRecordSummary fires
       'recordnavigate'; lnchatShell listens onrecordnavigate on c-lnchat-history.

Issue: record_summary items show names but no clickable links
Fix:   LNChatController.enrichSummaryRecordIds() runs after LLM callout and
       injects missing recordIds from context data. Without this, LLM may omit
       IDs and items render as plain text instead of clickable links.

Issue: Duplicate warning alert has no "Proceed Anyway" option
Fix:   Pass allow-bypass={alertAllowBypass} to c-lnchat-alert-banner in
       lnchatResponseRenderer. lnchatAlertBanner renders bypass buttons when
       allowBypass=true. alertproceed / alertcancel events bubble to lnchatShell.
       lnchatShell stores the pending action in _pendingBypassAction and
       re-calls handleRecordActionConfirm with bypassDuplicate=true.

Issue: Tests fail with "OpenAI API key not configured in AI_Config__mdt"
Fix:   AI_Config__mdt.Default record is excluded from deploy (.forceignore).
       Must be created manually via Setup UI after deploy. Once created, all
       tests pass. This is expected behavior for a fresh org.

Issue: Chart.js throws "Cannot add property _chartjs, object is not extensible"
Fix:   LWC reactive proxies are read-only. Clone chart data arrays with
       Array.from() before passing to Chart.js. Never pass LWC proxy arrays
       directly to Chart.js constructors.

Issue: Empty responses (finish_reason: length) from OpenAI
Fix:   Increase MaxTokens__c in AI_Config__mdt to 4096 or higher.
       Values ≤2000 cause responses to be truncated for large record contexts.
